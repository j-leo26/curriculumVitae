# Curriculum Vitae Web

**Curriculum Vitae Web** es un proyecto personal desarrollado con el objetivo de presentar mi perfil profesional de forma clara, visual y accesible a través de la web.

El proyecto funciona como una alternativa moderna al CV tradicional en PDF, permitiendo mostrar información académica, habilidades técnicas y perfil profesional mediante una interfaz sencilla y bien estructurada.

---

## Introducción

En un contexto donde la presencia digital es cada vez más importante, este proyecto surge como una solución para centralizar y presentar mi hoja de vida en un formato web, facilitando su consulta por parte de reclutadores, docentes y equipos de trabajo.

El enfoque principal del proyecto es la **claridad de la información**, el **diseño limpio** y la **correcta estructuración del contenido**, aplicando buenas prácticas de desarrollo frontend.

---

## Objetivo del proyecto

Desarrollar una página web que permita:

- Presentar mi perfil profesional de manera clara y ordenada.
- Mostrar información académica y habilidades técnicas.
- Servir como apoyo a procesos de postulación laboral o académica.
- Practicar y reforzar conceptos de desarrollo web frontend.

---

## Alcance

El proyecto incluye:

- Información personal y perfil profesional.
- Formación académica.
- Habilidades técnicas y conocimientos.
- Diseño responsive para distintos dispositivos.
- Estructura clara y fácil de mantener.

El sitio está pensado como una base que puede evolucionar con nuevas secciones o mejoras visuales a futuro.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Diseño responsive
- Buenas prácticas de maquetación web

---

## Requerimientos funcionales

- **RF1.** El sistema debe mostrar la información personal del usuario.
- **RF2.** El sistema debe presentar la formación académica.
- **RF3.** El sistema debe listar habilidades técnicas y conocimientos.
- **RF4.** El sitio debe ser accesible desde distintos dispositivos.
- **RF5.** El contenido debe estar organizado de forma clara y legible.

---

## Requerimientos no funcionales

- **RNF1.** El código debe estar correctamente estructurado y comentado.
- **RNF2.** El diseño debe ser limpio y profesional.
- **RNF3.** El sitio debe cargar de forma rápida.
- **RNF4.** El proyecto debe ser fácil de mantener y escalar.
- **RNF5.** La interfaz debe ser intuitiva y comprensible.

---
